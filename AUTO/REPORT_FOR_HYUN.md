## 2. 헤드셋 체크리스트 (우선순위 순)

1. **런 흐름 전체** — 메뉴 RUN → (처음이면 튜토리얼) → 카운트다운 → 섬 1 → CLEARED → 상자 카드 → 포털 → … → 섬 4 뒤 상점 → 섬 8 뒤 보스 → VICTORY. 중간에 멈추거나 패널이 안 뜨는 곳이 없는지.
   - 느낄 것: 다음에 무엇을 해야 할지 매번 바로 알 수 있는가.
2. **런 길이** — 끝 화면에 런 시간(m:ss)이 나온다. 계산값은 약 9.3분이다. **10분을 넘으면** `RunParams.EnemyHealthPerIsland`(0.15), `BossHealthMult`(6), Arena 봇 수 순서로 줄일 것.
3. **선택 패널 읽기·고르기** — 2.5 m 앞 카드 글자 크기, 패널 폭(카드 3장 = 약 ±29°), 핀치가 잘못 눌리지 않는지(새 패널은 0.4초 동안 입력을 무시).
4. **아이템 효과 체감** — Power Cell(데미지), Rapid Coil(연사), Focus Lens(노란 치명타 빔), Hull Plating(체력 바가 늘어남), Afterburner(속도), Shock Amp(쇼크웨이브 범위). 고른 뒤 차이가 느껴지는가.
5. **상점** — 가격·잔액이 보이는지, 살 수 없는 칸이 어둡게 표시되는지, REROLL 가격이 오르는지, LEAVE 후 포털이 뜨는지.
6. **난이도 곡선** — 섬 1–2는 쉽고, Elite·Horde·보스는 아이템 없이는 버거운 정도인지. 봇 2마리가 동시에 쏠 때 앉아서 감당할 만한지.
7. **일시정지·헤드셋 벗기** — 런 도중 메뉴·포커스 상실 → 타이머와 봇이 멈추고 이어서 할 수 있는지. MENU로 나간 뒤 RUN을 다시 누르면 새 런이 깨끗하게 시작되는지.
8. **퀵 매치·튜토리얼·조준 모드 2종** — 예전과 똑같이 동작하는지(회귀 확인).

## 4. 대신 내린 결정 요약 (자세한 내용·되돌리는 법: `AUTO/QUESTIONS_FOR_HYUN.md`)

- **R1**: 테이블탑 감지는 `WorldScale > 1.5`로 판단(씬 배선 불필요).
- **R2**: `big_chests` 테마는 Economy로 둠. Greed 단점 중 체력 −30%는 Hyperbolic(체력이 0이 되지 않게).
- **R3**: 같은 스탯끼리는 곱해서 합치고, 확률·감소류는 1−∏(1−x)로 합침.
- **R4**: 테마 상자 4종이 테마 7개를 묶어서 다룸. Big Chests는 모든 상자의 선택지를 +1. 포털 가중치는 첫 추정값. 빈 상자가 될 포털은 내지 않음.
- **R5**: **순서를 바꿨다** — 클리어 → 그 섬의 상자 열기 → 다음 포털 고르기(계획서와 다름). 섬 4 상자 뒤에 상점, 섬 8 뒤에 바로 보스. 동시에 나오는 봇은 최대 2마리. 적 스케일링은 섬 1 = ×1.0부터 시작.
- **R6**: 상점 가격은 섬 5 기준(×1.2), 리롤하면 4칸 전부 새로 뽑음.
- **R7**: 최대 체력이 오르면 현재 체력도 같이 오름. 치명타는 노란 빔으로 표시(숫자 없음).
- **R8**: `MatchPhase.Run`을 새로 넣어 일시정지·메뉴는 `MatchDirector`가 맡음. 봇은 1.5초 뒤 재등장. 섬마다 플레이어를 출발점으로 되돌림. Spiked 상자 대가는 상자를 열 때 냄.
- **R9**: 카드 설명은 줄바꿈 허용. 포털 라벨은 → 대신 두 줄. 카드가 4장이면 2×2 배치. 등급은 색과 단어로 함께 표시.
- **R10**: 메뉴는 3열×2행. 처음 RUN을 누르면 튜토리얼 뒤 런으로 감. 끝 화면에 런 시간 표시.

## 7. 최종 코드 리뷰 (R12, `33f3204..HEAD`, `.unity` 제외)

Critical·Important **0건**. 퀵 매치 중립성, 두 번째 런의 상태 초기화, 일시정지, 하드 룰(하한 25%·HP 1·유니크·Greed 전용)은 모두 확인됨. 고치지 않고 기록만 한 Minor:

1. **무시된 사망 = 공짜 완전 회복** — 포커스를 잃는 바로 그 프레임에 플레이어가 죽으면 런이 사망을 무시하고, `HeroHealthModel`의 자동 리스폰(3초)이 체력을 가득 채운다. 드문 경우. 수정안: 런 중에는 자동 리스폰을 끄는 플래그를 넣고, 사망은 일시정지 여부와 관계없이 처리.
2. **DEFEAT 화면 뒤에서 히어로가 다시 나타남** — 같은 자동 리스폰 때문이다. 보이기만 할 뿐 조작은 꺼져 있다. 1번과 같은 수정으로 해결된다.
3. **일시정지 프레임의 처치가 사라짐** — 크리스탈과 처치 수가 빠진다. Arena는 대신할 봇이 나오므로 진행이 막히지는 않는다.
4. **봇끼리 맞음** — 봇 2마리가 있을 때 앞의 봇이 뒤 봇의 빔에 맞을 수 있고, 그렇게 쓰러진 처치도 플레이어 몫으로 센다(R8에서 이미 알고 있던 점).
5. **`RunChoiceMenu.Awake`가 `run` 참조 없이 실행되면 오류** — 빌더가 항상 연결하므로 지금은 생기지 않는다. 수정안: `Choose(() => run.RerollShop())`처럼 람다로.
6. **메뉴로 돌아갈 때 한 프레임 동안 아이템이 적용된 최대 체력이 남음** — 화면에는 보이지 않는다.
