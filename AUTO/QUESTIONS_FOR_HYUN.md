    - 무엇을 하나: `ArenaLayoutParams.ViewerEyes`(아레나 좌표)를 새로 두었다. 기본값은 VR 좌석 눈 (0, -0.8, -20)과 TABLE 눈 (0, 7, -24.5)이다. TABLE 눈은 `ViewLayout.Tabletop`과 `TabletopParams.Default`로 계산한 값이고, 테스트가 이 둘이 맞는지 본다.
    - 이유: 4차 시야 규칙은 영웅 시작점(아레나 0, 0, 0)에서만 선을 그었다. 그런데 플레이어의 눈과 손 조준 광선은 좌석(0, -0.8, -20)에서 나간다. 바닥 조각은 이 높이까지 오지 않았지만, 발판(2–7.2 m)은 처음으로 그 사이에 놓이는 조각이다. 그래서 모든 규칙을 통과해도 발판 뒤에 스폰이 숨을 수 있었다. 예: 발판 (0, 3.7, 8), 스폰 (0, 5, 16). 새 테스트 2개는 고치기 전 코드에서 실패하는 것을 확인했다(좌석 눈 시드 57, TABLE 눈 시드 13).
    - 왜 발판만, 왜 "하나 이상": 바닥 조각까지 눈에서 검사하면 기둥 2개뿐인 4차 배치도 바뀐다. 지금은 발판이 없는 섬은 4차와 배치가 똑같다. "스폰 하나 이상"은 4차 시야 규칙과 같은 기준이다. 나머지 스폰은 발판 뒤에 있을 수 있고, 그것은 의도한 공중 엄폐다. 모든 행의 최대 개수에서 시드 200개가 대체 배치 없이 놓이는 것도 그대로다.
    - 뒤집으려면: 씬 `Match` > `ArenaLayoutApplier` > `Rules` > `Viewer Eyes` 배열을 비운다(4차·초안 규칙). 모든 스폰을 보이게 하려면 `ArenaLayout.HasOpeningSightLine`을 "모든 스폰의 눈 선이 발판을 피함"으로 바꾼다.
